# FM26 Squad Analysis

This package is ready to use as a static site on GitHub Pages.

## What is included

- `index.html`
- `app.js`
- `styles.css`
- `squad_analysis_lenses.json`
- `fm26_upload_template.csv`
- `fm26_sample_squad.csv`

## Publish on GitHub Pages

1. Create a new public GitHub repository.
2. Upload all files from this folder into the root of that repository.
3. Open **Settings -> Pages** in GitHub.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.
6. GitHub will publish the site and give you a permanent URL.

## Use the tool

1. Open the live site or `index.html` locally.
2. Upload `fm26_upload_template.csv` after filling it with your squad, or try `fm26_sample_squad.csv` first.
3. If you only have screenshots, send the screenshots and the template CSV to an AI tool and ask it to fill the rows in the same format.
4. Save the result as CSV and upload it in the app.
5. Then choose a match situation and review who fits, who struggles and where the squad is exposed.
