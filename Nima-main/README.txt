FM26 Squad Analysis

1. Download the folder, open `index.html`, and the tool runs locally in your browser with no install needed.
2. To use your own squad, either upload the CSV template and fill it in manually, or use the sample file first to see how the tool works.
3. If you only have screenshots, take clear pictures of your squad attributes, send the screenshots together with the template CSV to an AI tool, and ask it to fill the rows in the same format.
4. Save the finished file as CSV, upload it in the app, and then choose a match situation to see who fits, who struggles and where your squad may be exposed.
5. You can also add a few players manually inside the app if you want to test an idea before building a full squad file.
